# Architecture

SwiftUI views bind to one window-owned `@MainActor` coordinator. Sidebar destinations observe that shared coordinator, so navigation cannot cancel or lose active analysis/download tasks. The coordinator owns explicit task cancellation and receives ordered progress events; views never own network task lifetimes. It validates intent and calls injected provider/services but does not parse HTML or own networking. `AO3Client` obtains a cancellation-aware full lifecycle lease from the `AO3RequestScheduler` actor so metadata and file requests cannot overlap. `HTTPTransport` is replaceable in tests. `AO3HTMLParser` semantically parses bounded HTML. Downloads are staged by URLSession, verified, then moved to a collision-safe destination. Codable persistence uses atomic replacement.

The app is sandboxed for outbound networking and user-selected folder access. Series downloads are sequential and preserve selected author order. `EPUBMerger` extracts verified inputs into application staging, reads container/OPF manifests and spines, namespaces resources, and writes a new EPUB 3 package; `PDFMerger` inserts original PDFKit pages without rasterization. A combined book is never produced from a partial series. Future durable jobs will own resumable checkpoints. All downloaded markup and ebooks are untrusted data.
