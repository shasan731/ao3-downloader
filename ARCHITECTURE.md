# Architecture

SwiftUI views bind to one window-owned `@MainActor` coordinator. Sidebar destinations observe that shared coordinator, so navigation cannot cancel or lose active analysis/download tasks. The coordinator owns explicit task cancellation and receives ordered progress events; views never own network task lifetimes. It validates intent and calls injected provider/services but does not parse HTML or own networking. `AO3Client` obtains a cancellation-aware full lifecycle lease from the `AO3RequestScheduler` actor so metadata and file requests cannot overlap. `HTTPTransport` is replaceable in tests. `AO3HTMLParser` semantically parses bounded HTML. Downloads are staged by URLSession, verified, then moved to a collision-safe destination.

The app is sandboxed for outbound networking and user-selected folder access. Adult-warning consent is an explicit local preference; enabled work analyses add only AO3's `view_adult=true` parameter. A post-redirect work response must stay on the exact AO3 host and retain the requested work ID, permitting only its canonical path or one numeric chapter path. Browser/login cookies are not imported. Series downloads are sequential and preserve selected author order; this keeps AO3 request serialization strict while verification, local history writes, and assembly remain inexpensive. Selection is read immediately before each queued part and again before assembly, so a user can deselect later parts during a run. Every verified part and failure is checkpointed immediately in the versioned, atomic `LibraryStore`, together with a security-scoped destination bookmark. Combined-only jobs retain verified source books in a hidden project folder so future retry, metadata editing, and recombination do not require another network request.

`EPUBMerger` extracts verified inputs into application staging, reads container/OPF manifests and spines, namespaces resources, and writes a new EPUB 3 package; `PDFMerger` inserts original PDFKit pages without rasterization. Automatic assembly occurs only when the final selected subset is complete. Other failures remain retryable and no longer block combining a complete subset. `BookMetadataEditor` updates EPUB packages atomically and uses PDFKit for PDF metadata and managed covers. All downloaded markup and ebooks are treated as untrusted data.
