# User guide

Paste a public AO3 work/series URL or a public `https://www.fanfiction.net/s/…` story URL, select **Analyze**, review the preview, choose EPUB/PDF/HTML and a folder, then download. AO3 chapter URLs normalize to their whole work; FanFiction.net chapter URLs normalize to the complete story. Pasted URLs have surrounding whitespace removed automatically, Return analyzes the current URL, and the clear control resets the field. The application never asks for either site's password or imports browser cookies.

For FanFiction.net, ArchiveBind reads the public metadata and chapter list, then fetches each chapter sequentially through the shared courteous request queue. The Activity view shows chapters completed and the current chapter. EPUB and HTML output include a linked Contents page and return links; PDF output includes a clickable Contents page and chapter bookmarks. Formatting is sanitized before it enters the local book. FanFiction.net does not expose an AO3-style series object, so story URLs create one complete book rather than a selectable multi-story project.

For AO3, a series preview displays `Part N` beside every title, preserves author order, and provides individual toggles plus Select All/None controls. Its fixed-height part list keeps the window stable for large series; search by title or part number, or filter by All, Selected, Remaining, Failed, or Completed. For EPUB and PDF, choose **Separate files**, **One combined book**, or **Both**. HTML remains separate-file only. Restricted works must be opened in a browser.

Combined EPUB and PDF books include a title page and a visible Contents section. Each selected story/book is a top-level link; source chapters or bookmarked sections appear beneath it as indented links. Selecting an entry jumps to that book or chapter. EPUB readers also receive the same hierarchy in their navigation sidebar, styled reflowable front matter, book-opening divider pages, and return-to-Contents links. PDFs include page numbers, clickable Contents rows, and a matching bookmark outline while retaining the original source pages without rasterizing them. A normal single EPUB keeps AO3's official book layout and navigation; a single PDF is polished with a title page, linked Contents, and preserved source chapter bookmarks.

For a public work that shows AO3's Mature/Explicit warning, enable **Allow public Mature/Explicit works** beside the source URL or in Settings. This is equivalent to selecting AO3's **Yes, continue** action for app requests; it does not reuse browser cookies or sign in. If a series part already failed on that warning, enable the option and select **Retry** beside it. Login-only/restricted works and verification challenges remain unsupported. AO3 may redirect a multi-chapter work URL to its first chapter after consent; the app recognizes only a same-work chapter redirect and still downloads AO3's complete-work file containing every published chapter.

Analysis and downloads continue when you switch between New Download, Activity, Settings, or other sidebar sections. Activity shows the active phase, elapsed time, processed/total count, and current item. For FanFiction.net it reports real per-chapter progress. For AO3 series it also shows a status icon beside every part and automatically scrolls to the active part. You may change AO3 series selections while downloading: parts not yet started are skipped, and assembly uses the final selection. Because AO3 supplies a whole multi-chapter work as one file, chapter-level network progress is not fabricated for AO3. **Cancel** or Escape stops queued or active work and retains/checkpoints already verified files.

FanFiction.net sometimes returns a Cloudflare browser-verification page instead of a story. ArchiveBind reports this as a verification challenge and stops; it does not imitate a browser, reuse cookies, solve challenges, or save the challenge page as a book. Try later or read the story on the website. This behavior can vary by network and location.

Opening a Library item temporarily loads it into the shared workspace. Returning to **New Download** after that operation is idle starts with a clean form; it never deletes the Library record or downloaded files. Active work is not cleared when navigating.

If AO3 sends a `Retry-After` instruction, the app pauses its global request queue until that time and preserves the cooldown across relaunches. A connection outage or timeout is shown distinctly from an AO3 access/layout error. Nothing already verified is discarded; reconnect and use Retry when appropriate.

## Library, retries, and updates

Every started series becomes a durable Library project. Select it in **Library** to see verified, failed, missing-local, and inaccessible parts, including the reason beneath each failed title. Use **Retry** beside one failed part or **Retry Failed** to process the selected failures in order through the courteous request queue. Once every currently selected part has a green check, **Combine Selected** creates a new EPUB or PDF even if some unselected part failed. Source files are retained for combined-only projects, so recombination does not redownload them.

Library writes keep a last-known-good recovery copy. If the primary database is damaged, the app loads that copy instead of silently presenting an empty Library. Persistence problems are shown without deleting downloaded books. **Remove from Library** removes only the record after confirmation; it deliberately keeps all downloaded files and folders.

Change the checkboxes to build an anthology from any verified subset. Edit the title, comma-separated authors, language, and optional JPEG/PNG cover before combining. **Apply Metadata** updates an existing combined book atomically; **Edit Metadata** updates an individual downloaded part; single-work history has **Apply to File**. The original is left intact if validation of an edited replacement fails.

Reapplying PDF metadata replaces the app-generated cover/title/Contents pages instead of nesting or duplicating them. Recombining a saved project regenerates navigation from the currently selected source books, so its Contents always matches the final anthology.

Use **Reanalyze Source** in the Library item’s ellipsis menu to refresh a saved series. Existing selections and verified files are matched by AO3 work ID, new parts are shown as pending, and **Download Missing** fetches only the selected items not already retained. The format of an existing Library project stays locked because retained source books cannot safely be treated as another format.
