# User guide

Paste a public AO3 work or series URL (chapter URLs are normalized to their whole work), select **Analyze URL**, review the preview, choose AO3's offered EPUB/PDF/HTML format and a folder, then download. A series preview preserves author order and lets you deselect individual accessible works. Series output is currently separate files in a dedicated folder; failed or inaccessible entries remain visible and are recorded in `download-report.json`. Restricted works must be opened in a browser. The application never asks for an AO3 password.
