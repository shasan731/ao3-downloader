# User guide

Paste a public AO3 work or series URL (chapter URLs are normalized to their whole work), select **Analyze URL**, review the preview, choose AO3's offered EPUB/PDF/HTML format and a folder, then download. A series preview displays `Part N` beside every title, preserves author order, and provides individual toggles plus All/None controls. For EPUB and PDF, choose **Separate files**, **One combined book**, or **Both**. Combined output is created only when every selected work succeeds; otherwise verified individual files are retained and `download-report.json` records every inaccessible or failed entry. HTML remains separate-file only. Restricted works must be opened in a browser. The application never asks for an AO3 password.
