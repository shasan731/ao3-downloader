# ArchiveBind brand

ArchiveBind pairs the idea of an archive with the craft of binding selected stories into a personal book. The tagline is **Your stories, beautifully bound.**

The original icon uses a midnight-indigo bound volume, warm paper, and a coral downward bookmark/arrow. It should remain text-free and must not be combined with or mistaken for the AO3 logo.

## Assets

- `docs/assets/archivebind-icon-master.png` — source raster artwork.
- `docs/assets/archivebind-icon.png` — repository/README image.
- `AO3Downloader/Resources/Assets.xcassets/AppIcon.appiconset` — generated macOS icon sizes.

## Generation prompt

> Create one production-ready macOS application icon for an app named ArchiveBind, an unofficial local-first tool that saves public web fiction as polished ebooks. Original visual identity only; do not use or imitate the AO3 logo, Apple logo, or any existing brand mark. Subject: a refined closed bound book viewed in a gentle three-quarter perspective, with two warm parchment page edges subtly forming a downward arrow/bookmark motif at the center. Style: premium contemporary macOS utility icon, calm and trustworthy, strong simple silhouette at 16 px, tactile layered depth, soft studio lighting, restrained glass-like highlights, subtle shadow. Palette: deep midnight indigo and muted plum book cover, warm ivory pages, one restrained coral accent. Composition: centered object, generous safe margin, symmetric and uncluttered, no tiny details. Canvas: square 1024x1024, full-bleed soft blue-gray background inside an icon-like rounded-square field. No text, no letters, no watermark, no mockup device, no transparent checkerboard. Crisp edges and high contrast suitable for app-store-style display.

The generated source was resized with macOS `sips` for asset-catalog slots. Keep proportions and colors intact; do not add text at small sizes.
