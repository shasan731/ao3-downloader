# Changelog

## 0.1.3 (2026-11-01)

- Fixed long series previews expanding the app window in proportion to the number of stories by moving parts into a fixed-height lazy scroller.
- Added large-series search and status filters, saved/failed counters, a collapsible description, and automatic scrolling to the active download.
- Added whitespace-safe URL paste/analysis, a one-click URL clear control, Return-to-analyze, Escape-to-cancel, and a stable minimum window size.

## 0.1.2 (2026-10-27)

- Aligned the tag-release validation stages with the proven main-branch test and Release-build sequence.

## 0.1.1 (2026-10-27)

- Prepared the first public ArchiveBind release after the verified branding, responsive-interface, Library, packaging, and repository overhaul.

## 0.1.0 (2026-10-27)

- Added the native macOS SwiftUI foundation and public single-work download flow.
- Added strict URL validation, metadata parsing, courteous global scheduling, file verification, safe naming, persistence primitives, synthetic tests, and ad-hoc-signed CI packaging.
- Added selectable series downloads, valid combined EPUB/PDF output, cross-navigation task ownership, live per-part progress, cancellation-safe scheduler waits, and retained-output cancellation reporting.
- Added durable Library projects with per-part checkpoints, failure retry, live deselection, retained combined-book sources, arbitrary verified-subset recombination, series refresh/new-part discovery, and missing-only downloads.
- Added editable title/author/language/cover metadata for individual, single, and combined EPUB/PDF books, including atomic in-place EPUB package editing and managed PDF covers.
- Added explicit public Mature/Explicit consent handling, specific warning errors, safe same-work first-chapter redirects, complete multi-chapter part analysis, and in-place retry controls in the series preview.
- Added book-quality EPUB/PDF front matter: title pages, visible hierarchical Contents, clickable Book/Story → Chapter links, styled EPUB dividers, PDF page numbers/bookmarks, and duplicate-safe PDF metadata regeneration.
- Added persisted `Retry-After` handling, actionable offline/timeout errors, recoverable Library storage with visible checkpoint failures, ordered bulk retry, per-part failure details, safe Library removal, and completed-operation duration UX.
- Introduced the ArchiveBind name and original app icon, a refined responsive macOS interface, searchable and less cluttered Library details, and settings text that wraps in narrow windows.
- Kept New Download clean after browsing Library while preserving active cross-navigation operations and all durable history.
- Added an engaging repository home, user/privacy/troubleshooting/release documentation, contribution and security policies, issue forms, release notes, and stable release packaging.
